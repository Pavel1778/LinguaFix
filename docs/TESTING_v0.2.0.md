# Ручное тестирование v0.2.0

Этот чек-лист — для живой системы (Debian 13 + GNOME 48, X11 или Wayland).
Моки в тестах покрывают логику, но не интеграцию с GNOME, AT-SPI, буфером
обмена и реальной раскладкой. **v0.2.0 не публикуется, пока этот чек-лист не
пройден.**

Проверять нужно на **своей машине**, а не в контейнере: в контейнере нет
`/dev/input`, `/dev/uinput`, клавиатуры и сессии GNOME.

## 0. Подготовка

```bash
# собрать и поставить .deb из feat-ветки
bash scripts/build_deb.sh
sudo apt install ./dist/linguafix_0.2.0_all.deb

# перелогиниться (пакет включает systemd user-сервис глобально)
linguafix --version            # ожидается 0.2.0
linguafix doctor
```

Пути, которые понадобятся:

| Что | Путь |
|---|---|
| Конфиг | `~/.config/linguafix/config.toml` |
| Словарь | `~/.local/share/linguafix/dictionary.txt` |
| Сниппеты | `~/.config/linguafix/snippets.toml` |
| Лог демона | `~/.local/state/linguafix/linguafix.log` |
| Лог GUI | `~/.local/state/linguafix/gui.log` |
| PID-файл | `~/.cache/linguafix/daemon.lock` |

Перед тестом откройте второй терминал с хвостом логов:

```bash
tail -f ~/.local/state/linguafix/linguafix.log
```

Включить подробный лог: в конфиге `log_level = "DEBUG"`, затем
`linguafix restart` (или `pkill -HUP -f 'linguafix start'`).

## 1. Базовое (регрессии v0.1.0 — обязательны)

- [ ] `linguafix doctor` — все пункты ✅ (или понятные ⚠️ с объяснением).
- [ ] `linguafix start --foreground` — демон запускается без ошибок, видно
      `LinguaFix started (N device(s), ...)`.
- [ ] **`ghbdtn ` → `привет `** — мгновенно, **без обрезания** (не `рhello`,
      не `ривет`). Проверить в трёх местах: GNOME Text Editor, Firefox
      (адресная строка), терминал (GNOME Terminal / kitty).
- [ ] **`руддщ ` → `hello `** — без обрезания первой буквы.
- [ ] `c` в русской раскладке + английское слово (`bylj` → `dns`)? —
      ложных срабатываний на нормальных словах нет.
- [ ] **Двойной Shift** на `ghbdtn` → `привет` (в ручном режиме и в hybrid).
- [ ] Одиночный Shift (обычный заглавный символ) — fix **НЕ** срабатывает.
- [ ] `linguafix mode manual`, набрать `ghbdtn ` — не трогает; двойной Shift —
      исправляет; `linguafix mode hybrid` — исправляет по границам слова;
      `linguafix mode auto` — вернуть обратно.
- [ ] **Undo:** после fix нажать `Shift+Backspace` → текст возвращается как
      было.
- [ ] URL/почта/путь не переписываются: наберите `https://example.com/a_b `,
      `user@example.com `, `/usr/local/bin ` — ничего не меняется.
- [ ] Текст в **поле пароля** (`sudo` в терминале, логин Firefox) — не
      исправляется (см. раздел 2, это же и есть проверка password guard).

## 2. Новые фичи v0.2.0

### 2.1 AT-SPI: защита полей паролей (`password_guard`, по умолчанию `true`)

- [ ] В терминале наберите `sudo echo ghbdtn` — пароль/команду **не**
      исправляет (слово `ghbdtn` после Enter не превращается).
- [ ] В Firefox на странице логина наберите `ghbdtn` в поле пароля — не
      исправляет.
- [ ] В обычном текстовом поле при этом `ghbdtn` всё ещё исправляется.

> ⚠️ AT-SPI может не работать на GNOME 48. Проверить обязательно. Если не
> работает — записать в отчёт, это кандидат в фикс, но не блокер релиза
> (фича защитная, при отказе просто не срабатывает).

### 2.2 T9: исправление опечаток (`typo_correction`, по умолчанию `false`)

- [ ] Включить: `typo_correction = true` в конфиге, затем `linguafix restart`.
      (Или GUI → **Дополнительно** → «Исправление опечаток (T9)».)
- [ ] Наберите `превет ` → `привет ` (если срабатывает).
- [ ] Наберите `программирование `, `привет ` — корректные слова **не**
      портятся.
- [ ] Если ложно срабатывает на реальных словах — записать примеры и
      **выключить** (`typo_correction = false`). По умолчанию выключено не
      просто так.
- [ ] `typo_max_distance = 2` — шире, но больше ложных срабатываний.

### 2.3 TextExpander: сниппеты (`text_expander_enabled`, по умолчанию `false`)

- [ ] Создать `~/.config/linguafix/snippets.toml`:

      ```toml
      [snippets]
      "!!email" = "user@example.com"
      "!!shrug" = "¯\\_(ツ)_/¯"
      "!!date" = "{date}"
      ```

- [ ] Включить `text_expander_enabled = true`, `linguafix restart`.
- [ ] Набрать `!!email ` → `user@example.com `.
- [ ] `!!date ` → сегодняшняя дата.
- [ ] Триггер не «исправляется» в другую раскладку до раскрытия.

### 2.4 Selection Fix (`selection_fix_enabled`, `selection_fix_hotkey=CTRL+SHIFT+L`)

- [ ] Выделить `ghbdtn` в любом поле, нажать `Ctrl+Shift+L` → `привет`.
- [ ] Работает и когда фокус не в терминале.
- [ ] Выделенный русский текст с хоткеем не портится.

> ⚠️ Самое рискованное: работает через буфер обмена (`wl-copy`/`wl-paste` +
> эмуляция Ctrl+C/Ctrl+V). В GNOME Wayland может не работать. Если ломается —
> это **не блокер**, достаточно выключить `selection_fix_enabled = false`.
> Записать в отчёт.

### 2.5 Per-App Layout (`app_layout_switch`, по умолчанию `false`)

- [ ] GUI → **Дополнительно** → привязка приложений к раскладке (например,
      `kitty` → `ru`). Или в конфиге `app_layouts = { kitty = "ru" }`.
- [ ] Включить `app_layout_switch = true`, `linguafix restart`.
- [ ] Переключиться на `kitty` → раскладка становится `ru`.
- [ ] Переключиться на другое приложение → раскладка не «залипает».
- [ ] Нет конфликта с GNOME (нет дрожания раскладки при переключении окон).

### 2.6 Auto-update (`update_check_enabled`, по умолчанию `false`)

- [ ] Включить в GUI → **Дополнительно** → «Проверять обновления» (или
      `update_check_enabled = true`), `linguafix restart`.
- [ ] В логе появляется запрос к GitHub (при `log_level=DEBUG`). Сейчас
      установлена 0.2.0 — уведомления об обновлении быть не должно.
- [ ] Проверить, что при выключенном флаге сеть не дёргается вообще.

## 4. Если что-то не работает

1. Запишите **точно**: раскладку, приложение, что набрали, что получилось,
   что ожидали.
2. Логи:
   ```bash
   tail -n 200 ~/.local/state/linguafix/linguafix.log
   tail -n 100 ~/.local/state/linguafix/gui.log
   linguafix doctor
   ```
   Для отчёта об ошибке: `linguafix collect-logs` — соберёт архив.
3. Пришлите всё в чат.
