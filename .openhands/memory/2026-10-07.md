## v0.2.2 iteration — ЭТАП 1 diagnosis (4 bugs)
1. **`linguafix stop` doesn't work (P0)** — `cli.cmd_stop` (cli.py:133) only SIGTERMs the lock-file PID; it never calls `daemon_control.stop()`, so it never runs `systemctl --user stop`. Under the .deb the unit is `Restart=always`, so systemd respawns the daemon ~5 s later. GUI works because it uses `daemon_control.stop()`. Fix: route cmd_stop (and cmd_kill/restart) through daemon_control.
2. **T9 never fires (P1)** — logic is CORRECT (proven: `_typo_correction('превет','ru') == 'привет'`; full key pipeline `превет`+Space → replacement `(7,'привет ','ru')`). Real cause: the running daemon holds its own startup `Config`; GUI `GuiState.save()` writes config.toml but does NOT SIGHUP the daemon. Proven: file says `typo_correction=true`, daemon still no-ops; after reload → corrects. Only the T9 master big button (`typo_page._on_toggle_clicked`) calls `state.reload_config()`; the per-row switches (`_on_switch`) do not. Fix: push config to the daemon on every GUI save.
3. **Window resizes by itself / breaks (P0)** — `window.py`: `ViewSwitcherTitle` `title-visible` is bound to `switcher_bar.reveal` (window.py:59-66) AND `notify::default-width` handler `_on_width_changed` also writes `reveal` with a different threshold 560 (window.py:88-89). Two writers of one property. Aggravated by `_on_show_advanced` (window.py:114) `add_titled()` at runtime (6th page) which changes the homogeneous ViewStack width → `title-visible` flips → bar churn; and the default-homogeneous ViewStack makes the window's natural height the max over all pages. No `ScrolledWindow` anywhere.
4. **Button ugly (P2)** — `big_toggle.py` is a plain `Gtk.Button` with classes `circular big-toggle active-state busy-state` and **no CSS file exists anywhere** (no `CssProvider` loaded). Icon is `input-keyboard-symbolic`, not `power-symbolic`. No halo, no animation.
Env note: this container has NO gi/GTK typelibs now (`.venv` py3.13 lacks gi; system has no python3-gi/girepository). GUI can only be tested in CI's GUI job.
