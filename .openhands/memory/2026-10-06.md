## Gotchas learned
- `ruff format` breaks CI black on `tests/test_data_sync.py` — reverted; use `ruff check --fix`
  only, black is the formatter.
- `Gio.BindingFlags` is not exposed; use `GObject.BindingFlags`.
- Heredoc file writes echo mangled previews (stray chars) but the file on disk is fine — always
  `py_compile` / `cat -A` to confirm; don't trust the echoed preview.
- Anchor-based method insertion stranded the tail of `_typo_correction`; the typo test caught it.
  Verify method boundaries after such inserts.
- GLib callbacks only fire when a main loop iterates; tests must pump
  `GLib.MainContext.default().iteration(False)`.
