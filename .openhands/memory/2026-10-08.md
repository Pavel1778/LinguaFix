## Env quirk (cost ~30 min)
- The shell session exports `LD_LIBRARY_PATH=/usr/lib/aarch64-linux-gnu:/usr/lib:/usr/lib/x86_64-linux-gnu:`
  — the **aarch64 path first**. This makes `/usr/local/bin/python3.13` segfault
  on `import ctypes` (libffi). **`unset LD_LIBRARY_PATH LD_LIBRARY_PATH_ORIG`**
  before running pytest; otherwise the whole suite dies at import. `/usr/bin/python3`
  happened to survive; the venv python did not.

## v0.2.6 (third session 2026-10-08)
- **SIGUSR2 spam (P0-1), real fix**: the daemon now writes its history snapshot
  ITSELF. `_record_undo` calls `_write_history_snapshot(history=...)` on the
  event-loop thread; `_write_history_snapshot(history=None)` accepts an optional
  payload. GUI `state.read_history()` only reads `history.json` via
  `daemon_control.read_history` — no signal. Root cause of the v0.2.5 miss:
  gating the tab timer removed the *reader*, but the daemon's per-fix write was
  never triggered without the signal, so the snapshot went stale and the GUI
  re-signalled.
- **`typo_correction` reset (P0-2), real root cause**: `daemon._persist_config`
  dumped its whole in-memory `self.config` over the file. The daemon's copy is
  often stale (GUI saves a key, daemon later cycles mode -> full overwrite).
  Fix: `_persist_config` now `load_config()` first, sets only `.mode`, saves.
  (The v0.2.5 `Config._drop_invalid` fix covered a *different* path — a bad
  hand-edit.) Test `test_persist_config_does_not_clobber_other_fields`.
- **Short-word hotkey**: `detector.forced_short_layout(text, current_layout)`
  returns the taught/converted target ignoring length; daemon forces it on the
  explicit fix hotkey for tokens < `min_word_length`. Ambiguity guards: target
  must be a known word of the target lang AND text not a word of current lang;
  taught words always win. Ambiguous (`а`->`f`, `ты`->`ns` real word) left alone.
  Level-3 lookup must include `user_words`.
- **Doctor GUI check**: `doctor.check_gui_libraries()` -> new row "Графический
  интерфейс", hint `sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1`.
  GUI stack is only a `Recommends` in the `.deb`; `--no-install-recommends`
  previously left a bare failure. README/TROUBLESHOOTING document it.
- Home tab status poll also visibility-gated now.
- Version 0.2.5 -> 0.2.6 across `__init__.py`, pyproject, `site/src/consts.ts`,
  `Base.astro`, `site/package.json`; CHANGELOG `[0.2.6]`.
- **Tooling trap (repeat!)**: `ruff format` and `black` DISAGREE (ruff collapses
  a dict to one line, black keeps it split). CI runs **black --check**, so run
  `black .` (not `ruff format`) before pushing. Full set: `black`, `isort`,
  `ruff check`, `mypy --strict .` (tests included).
