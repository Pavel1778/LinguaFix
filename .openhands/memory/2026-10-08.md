## Env quirk (cost ~30 min)
- The shell session exports `LD_LIBRARY_PATH=/usr/lib/aarch64-linux-gnu:/usr/lib:/usr/lib/x86_64-linux-gnu:`
  — the **aarch64 path first**. This makes `/usr/local/bin/python3.13` segfault
  on `import ctypes` (libffi). **`unset LD_LIBRARY_PATH LD_LIBRARY_PATH_ORIG`**
  before running pytest; otherwise the whole suite dies at import. `/usr/bin/python3`
  happened to survive; the venv python did not.

## v0.2.5 (second session 2026-10-08)
- **User bug reports triaged from real `doctor`/DEBUG logs** (all devices/uinput
  OK; GNOME 48 out of declared 42–45 range but works; backend=g3kb-switch,
  session=wayland).
- **`typo_correction` reset root cause (CONFIRMED)**: `Config.from_dict` did
  `cls(**filtered)` and on **any** single `ValueError` returned `cls()` = *all*
  defaults. One bad hand-edited value silently wiped every setting, incl. T9.
  Fixed: `Config._drop_invalid` removes only the offending keys. Regression
  tests `test_from_dict_keeps_valid_keys_when_one_is_invalid`,
  `test_reinstall_preserves_config`. (Reinstall never rewrites config: `postrm`
  only removes on `purge`; `load_config` never writes when the file exists.)
- **Same-layout correction guard**: `daemon._process_buffer_inner` refuses a
  replacement when `target == self.switcher.current` (logs warning). Log line is
  now `Fixing buffer of length %d (%s -> %s) reason=%s` (reason =
  layout/typo/punctuation). Reported `Fixing buffer ... (ru -> ru)` was the
  detector returning the CURRENT layout and deforming text.
- **SIGUSR2 log spam**: `HistoryPage` polled every 2 s regardless of tab
  visibility. Now visibility-gated (`_tick` no-op unless mapped; refresh on
  `map` signal), interval 3000 ms. `tests/test_gui.py::test_history_page_does_not_poll_while_hidden`.
- **Icon fallback**: `big_toggle` gained a Cairo `PowerGlyph` (draws the power
  ring+bar) used when the theme cannot resolve `system-shutdown-symbolic`;
  `_build_icon`/`icon_name`/`theme_has_icon`. Needed because a theme that does
  not inherit Adwaita rendered a broken-image placeholder.
- **`linguafix logs`** new CLI (`src/linguafix/logs.py`): `read_tail`/`follow`,
  `-n`, `-f`, `--level`. `logs.py` only 55 % covered (subprocess/`tail` path is
  env-dependent) but TOTAL stays 86 %.
- `backspace_settle_ms` default 80→120 (+ `DEFAULT_TRIGGER_SETTLE_MS=50`).
- Release v0.2.5: commit `2b440df` + fixup `bf14ff9` (test annotations), tag
  `v0.2.5`, GitHub Release with `.deb`/sdist/SHA256SUMS; CI + Release green.
- **Tooling trap**: local `mypy src/linguafix` is NOT what CI runs. CI runs
  **`mypy --strict .`** over tests too (`no-untyped-def` on untyped test
  helpers/monkeypatch args). Always run `.venv/bin/python -m mypy --strict .`
  before pushing a new test module.
- **Release-tag recovery**: to re-release, delete the GitHub release
  (`DELETE /repos/:o/:r/releases/:id`), delete the remote tag ref
  (`DELETE /repos/:o/:r/git/refs/tags/vX.Y.Z`), re-tag the green commit, push.
  The release workflow only fires on tags matching `v[0-9]+.[0-9]+.[0-9]+`.
